This browser can't talk to USB devices. Open the page in Google Chrome or Microsoft Edge on a computer.

Connect the switch

  1. Plug the switch into this computer with a USB cable.
  2. Close the Arduino Serial Monitor if it's open.
  3. Click Connect and choose the switch from the list.

Setup happens over the USB cable – no Wi-Fi. Recordings and typed words stay on this computer.

What the switch does

4 quick messages for SPEAK mode: the switch plays the selected one. Click Change to record, type or upload a message.

4 topics of up to 4 messages for CHOOSE mode, where the student picks a message by scanning. Name each topic and message – the names are spoken as the prompts.

In IR mode the switch sends the selected remote-control code. Give a code a sound (e.g. "Bubbles!") and the switch says it as it sends – leave it out for silence.
To learn a code: click Learn, point the remote at the end of the switch from 30cm–1m away and press its button within 8 seconds.

Key the switch presses in KEYBOARD mode
Custom key or shortcut

For example Win + H starts Windows dictation. The custom key is added to the list above.
